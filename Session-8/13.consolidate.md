# Session 8 --- Consolidation / Quick Revision

## Three major things learned

### 1. Sigmoid & log-odds

The sigmoid converts a linear score into a probability:

\[ `\sigma`{=tex}(z)=`\frac{1}{1+e^{-z}}`{=tex} \]

Logistic regression is linear in the log-odds:

\[ `\log`{=tex}`\left`{=tex}(`\frac{p}{1-p}`{=tex}`\right`{=tex}) =
`\beta`{=tex}\_0+`\beta`{=tex}\_1x_1+`\cdots`{=tex} \]

Remember:

> **Linear score → sigmoid → probability**

------------------------------------------------------------------------

### 2. Log-loss

Log-loss comes from the Bernoulli likelihood and strongly penalizes
confident wrong predictions.

Remember:

> **Confident + wrong = huge loss**

------------------------------------------------------------------------

### 3. Classification metrics

Important metrics:

-   Precision
-   Recall
-   F1
-   ROC
-   AUC
-   PR-AUC

Key formulas:

\[ Precision=`\frac{TP}{TP+FP}`{=tex} \]

\[ Recall=`\frac{TP}{TP+FN}`{=tex} \]

\[ F_1=2`\frac{PR}{P+R}`{=tex} \]

\[ TPR=`\frac{TP}{TP+FN}`{=tex} \]

\[ FPR=`\frac{FP}{FP+TN}`{=tex} \]

------------------------------------------------------------------------

# Two things to remember

## 1. Threshold is a decision, not the model

The model produces probabilities/rankings.

The threshold decides how those probabilities become class labels.

So:

``` text
Model → probability
Threshold → decision
```

------------------------------------------------------------------------

## 2. Gradient intuition

The session summarizes the gradient idea as:

> **gradient = error × feature**

The basic intuition is that the size and direction of a parameter update
depend on:

-   how wrong the prediction is
-   the feature value

------------------------------------------------------------------------

# Interview question

A useful interview question from the session is:

> **When is ROC-AUC the wrong metric, and what do you use instead?**

For highly imbalanced problems where the positive class is rare, the
session highlights **PR-AUC** as a useful alternative because it focuses
directly on precision and recall.

------------------------------------------------------------------------

# Ultra-short cheat sheet

``` text
Sigmoid:
z → probability

Odds:
p / (1-p)

Log-odds:
log(p / (1-p))

Log-loss:
punishes confident wrong predictions

Threshold:
probability → class

TP:
predicted 1, actual 1

TN:
predicted 0, actual 0

FP:
predicted 1, actual 0

FN:
predicted 0, actual 1

Precision:
TP / (TP + FP)

Recall:
TP / (TP + FN)

F1:
harmonic mean of precision and recall

ROC:
TPR vs FPR

AUC:
ranking quality

Imbalance:
accuracy can be misleading

Rare positives:
consider PR-AUC
```
