Machine Learning
→ Learn patterns/rules from data

Supervised Learning
→ X + y → learn X → y

Unsupervised Learning
→ X → discover structure

Regression
→ Predict continuous values

Classification
→ Predict categories/classes

Generalization
→ Perform well on unseen data

Overfitting
→ Training performance very good, unseen performance much worse

Underfitting
→ Model performs poorly even on training data

Train Set
→ Used to learn the model

Validation Set
→ Used for model/hyperparameter selection

Test Set
→ Final evaluation on unseen data

Data Leakage
→ Information improperly crosses into training

RMSE
→ Lower is better; same units as target

R²
→ Higher is generally better; not accuracy

Monitoring
→ Check model after deployment because the world changes
